University Website

A responsive university website built using HTML, CSS, and JavaScript. The project presents university information through a clean, user-friendly interface with dedicated pages and sections for courses, campus facilities, student testimonials, and contact information.

Features

- Home Page: University landing page with a banner and navigation menu.
- About Page: Information about the university.
- Courses Section: Displays Intermediate, Degree, and Post Graduation learning pathways.
- Global Campus: Showcases campus locations and related imagery.
- Facilities Section: Highlights facilities such as the library, playground, and cafeteria.
- Student Testimonials: Displays student feedback with star ratings.
- Contact Page: Provides contact information and a contact form.
- Responsive Design: CSS styling for different screen sizes.
- JavaScript Enhancements: Supports interactive website elements where implemented.

Technologies Used

- HTML5
- CSS3
- JavaScript

How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" using the Live Server extension, or open the HTML file directly in a browser.
4. Navigate through the pages to explore the website.
